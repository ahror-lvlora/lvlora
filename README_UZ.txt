LVLORA — kompyuterga yuklab ishlatish
=====================================

1) TEZ ISHGA TUSHIRISH (internetsiz, hech narsa oʻrnatmasdan)
   - ZIP ni istalgan papkaga oching (ichidan chiqarib oling!).
   - Windows: "LVLORA_Windows.bat" ustiga ikki marta bosing.
     (Edge yoki Chrome bor boʻlsa, ilova alohida oyna sifatida ochiladi.)
   - macOS: "LVLORA_Mac.command" (birinchi marta: oʻng tugma > Open).
   - Linux: "LVLORA_Linux.sh".
   - Yoki oddiygina "index.html" ni brauzerda oching.
   Maʼlumot shu kompyuterdagi brauzer xotirasida saqlanadi. Brauzer maʼlumotini
   tozalasangiz, progress oʻchadi.

2) HAQIQIY "OʻRNATILADIGAN ILOVA" (Windows/Mac/Linux/Android) — TEKIN
   Papkani bepul hostingga joylang (masalan GitHub Pages yoki Cloudflare Pages).
   Sayt ochilgach Chrome/Edge manzil satrida "Oʻrnatish" (Install) tugmasi chiqadi —
   bosing: LVLORA ish stolida va Start menyuda oddiy ilova boʻlib turadi,
   internetsiz ham ishlaydi. Telefonda: Chrome > ⋮ > "Add to Home screen / Install app".

3) APK (Android) YARATISH — TEKIN
   Saytingiz https manzilga chiqqach: pwabuilder.com ga kiring, manzilni kiriting,
   "Package for stores" > Android > "Download". Oʻzingizning kalitingiz bilan imzolangan
   APK/AAB olasiz. APK ni telefonga oʻzingiz oʻrnatish bepul.
   Google Play'ga qoʻyish uchun Google dasturchi hisobi kerak (bir martalik toʻlov,
   yangi shaxsiy hisoblarga sinov testi talablari boʻlishi mumkin — Google
   qoidalarini nashr oldidan tekshiring). Imzo kalitini (keystore) yoʻqotmang.

4) NASHR OLDIDAN
   - privacy.html dagi [aloqa email manzilingiz] oʻrniga oʻz manzilingizni yozing
     va shu sahifani ommaviy URL ga joylang (Play talab qiladi).
   - Shartlar va maxfiylik matnlarini yuristga koʻrsating (men yurist emasman).
   - Oldingi bloklangan akkauntlar bilan bogʻliq qoidalarni (bir nechta akkaunt ochish,
     bloklarni aylanib oʻtish) buzmang — yangi akkaunt ochishdan oldin platforma qoidalarini oʻqing.
   - Ilovada pulli xarid, tasodifiy quti, reklama yoʻq; coin/EXP faqat oʻyin ichidagi ball.
   - "Solo Leveling" nomi, personajlari va atamalari ishlatilmagan; nomga ham, tavsifga ham
     yozmang.

Tillar: Oʻzbekcha, English, Русский (Sozlamalar > Til).
